# LinkedIn — ORBITIQ
Excited to share ORBITIQ, an independent engineering research project exploring how AI can help manage
satellite-to-cellular connectivity. It fuses public cellular data (OpenCelliD) and public orbital data (CelesTrak)
into a digital twin with 10k+ simulated devices, adds ML for anomaly detection and degradation prediction
(F1 0.81 / ROC-AUC 0.97 on held-out data), an explainable satellite-handoff optimizer, what-if outage simulation,
and a grounded GenAI operations copilot. Stack: Python, FastAPI, React, MapLibre, scikit-learn, Docker.
Independent prototype — no proprietary data, no SpaceX affiliation.
